How it works

Built for the way developers work

Claude Code understands your project, then takes direct action. No UI to switch to. No copy-pasting. Just your terminal.

Reads your whole codebase

Before touching a line, Claude Code reads relevant files, git history, and docs. It understands your architecture, naming conventions, and existing patterns before writing a single character.

Takes real action in your repo

Claude Code edits files, runs your tests, executes terminal commands, and creates commits. It doesn't suggest — it does. You review the diff and approve, or let it run autonomously.

Works with your tools

Use it as a CLI, or via IDE extensions for VS Code and JetBrains. Claude Code integrates with your existing workflow — git, npm, make, whatever your project uses.
